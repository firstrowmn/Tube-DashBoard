# Metro Link Dashboard

Дашборд и backend API контроля качества связи АКП Новосибирского метрополитена.

## Что реализовано

- главная страница с 14 станциями;
- зелёный / жёлтый / красный статус станции;
- переход на страницу станции;
- разбиение по вестибюлям/линейкам;
- таблица: АКП, IP, процент потерь, индикатор;
- пороги: >10% жёлтый, >30% красный;
- у «Речного вокзала» предусмотрено четыре линейки;
- справочник оборудования вынесен в `data/equipment.json`;
- рекомендации по интеграции — `docs/backend.md`.
- приём пятиминутных JSON-пакетов с API-ключом;
- хранение последних значений и истории;
- дедупликация по `deviceId + measuredAt`;
- серый статус при отсутствии данных новее 12 минут;
- документация для метрополитена — `docs/metro-api.md`.

## Важно

Реальные номера АКП и IP пока не подставлены: в браузере используется явно помеченный DEMO-набор. После импорта `НСК_Метрополитен_терминалы.xlsx` файл `data/equipment.json` заполняется реальными данными, строки с номером КП `MT` исключаются.

## Локальный запуск с API

```bash
METRO_API_KEY=change-me node server/index.js
```

Открыть `http://localhost:8080`.

## GitHub Pages

Фронтенд остаётся статическим и может публиковаться из ветки `main`, корень `/`. Адрес развёрнутого API задаётся в `config.js`. Инструкции по backend находятся в `docs/backend.md`.

# Рекомендация по бэкенду

## 1. Разделить справочник и телеметрию

Справочник оборудования хранится на нашей стороне и строится из Excel:

`station -> vestibule/turnstileLine -> AKP -> IP -> deviceId`

Строки, где номер КП равен `MT`, не импортируются.

Для идентификатора лучше использовать **стабильный `deviceId`/TID**, если он однозначен и не меняется при смене IP. IP оставить дополнительным атрибутом. Привязываться только к IP рискованно: адрес может поменяться.

## 2. Что должен передавать метрополитен

Рекомендуемый вариант — HTTPS REST API, `POST`, JSON UTF-8.

Endpoint, например: `POST /api/v1/link-loss`

```json
{
  "source": "novosibirsk-metro",
  "generatedAt": "2026-08-30T10:19:00+07:00",
  "measurements": [
    {"deviceId":"TID-123456","ip":"10.20.30.41","lossPercent":4.7,"measuredAt":"2026-08-30T10:18:30+07:00"},
    {"deviceId":"TID-123457","ip":"10.20.30.42","lossPercent":18.2,"measuredAt":"2026-08-30T10:18:30+07:00"}
  ]
}
```

Минимально обязательные поля: `deviceId`, `lossPercent` (0..100), `measuredAt`. `ip` можно передавать для контроля, но не использовать как единственный ключ.

## 3. Логика статусов

- `0 <= lossPercent <= 10` — зелёный;
- `10 < lossPercent <= 30` — жёлтый;
- `lossPercent > 30` — красный;
- если данных давно нет — отдельный серый `NO DATA`.

Статус линейки/вестибюля = худший статус среди её АКП. Статус станции = худший статус среди всех её АКП.

## 4. Доставка

Оптимально: метрополитен каждые 1–5 минут отправляет агрегированный пакет JSON на HTTPS endpoint. Альтернативы: SFTP с JSON/CSV, API внутри VPN или pull-модель. CSV `IP;lossPercent` возможен, но хуже JSON из-за отсутствия стабильной схемы, времени замера и идентификатора.

## 5. Безопасность

HTTPS; API key или mTLS; IP allowlist/VPN; логирование; валидация 0..100; дедупликация по `deviceId + measuredAt`; хранение истории 30–90 дней.

## 6. API для фронта

Фронт получает данные только от нашего бэкенда:

`GET /api/v1/stations`

`GET /api/v1/stations/{stationId}`

Ответ уже содержит вычисленный status и актуальный процент потерь каждого АКП.
